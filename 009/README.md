Almost entirely a product teardown. Josh Guter demos the AI assistant running Elephants, his ops platform for small teams, then spends the back half getting grilled on what every founder shipping an AI chat feature actually loses sleep over: which model, what it can touch, how you stop it doing something dumb, and how you audit a system too complex to fully read anymore.

## What we cover

- 64 tools, one job each — search relationships, search projects, stage a card — each with tight instructions on when the model reaches for it
- Nothing writes without a click: "create 10 catering tasks" comes back as cards you review and add; deletes and archives always need a human, even in auto mode
- Breadcrumbs instead of a black box: every tool call, error, and decision path logged to a table he can pull up when a customer says the assistant did something weird
- "That's kind of scary" — how much of his own codebase has gone opaque to him, and opening a fresh Claude Code session to explain it "like I'm 5"
- Illustrator mockup → Claude plan → Codex teardown, a build loop that starts in Adobe Illustrator from his graphic communications degree
- Red-teaming himself in a dedicated assistant stress test space, including trying to make it mass-delete every note in a workspace
- Glide + Make.com to full-stack: the rebuild ran on Opus 4.8 with Codex reviewing, using the old Make scenarios as the literal spec
- Six months running NC State's Entrepreneurship Clinic — asked which contacts to check in with before a leadership transition, and it surfaced the right four or five from conversation history
- A PWA on purpose: no App Store, identical on desktop, mobile browser, or installed to a home screen
- "Neck deep in AI psychosis" — the honest solo-founder moment, and what keeps him grounded
