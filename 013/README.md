Our first inbound guest. By day Craig has spent twenty-five years getting decision-intelligence software into production at banks. On the side he runs a two-year-old software factory that plans, builds, tests, and audits its own work, and Blind Oracle, an agent trust layer, is its first product.

## What we cover

- **"Solution engineer is a less sexy name for forward deployed engineer"** — Lockheed to Mantas to Quantexa, test manager to field engineer, and the prediction that every new title converges back
- **"The baby" turned one in June** — kept completely separate from the day job, and running on a GCP VM from day one instead of a Mac mini in the bedroom
- **Blind Oracle** — counterparty risk between agents: a one-click passport, delegation posted on-chain, and proof you can hand a lawyer without having to trust Craig
- **"I'm not trying to sell to humans. I'm trying to sell to robots."**
- **The software factory** — signals in from X, YouTube, GitHub stars, email, Telegram, WhatsApp, and the phone; Opus and Fable write the plans; Craig approves; a build system ships; governance checks design, implement, test, and deploy
- **Paste an article, ask "what am I missing?"** — a live run in Claude Code that comes back with what's built, what isn't, and what would change the conclusion
- **The CEO tweeting the CTO** — the hosts' read on handing "do we do this yet?" to an agent running a skill instead of micromanaging the build
- **Deliberation** — five to seven models with different personas, trailblazer to devil's advocate, argue the same context and return a confidence-scored recommendation
- **The governance ring** — alignment, autonomy, durability, self-improvement, self-reliance, and organization as the north star, audited weekly, reporting what it fixed rather than what's broken
- **"There's been nothing behind these things"** — scorecard metrics that turned out to be hollow until a smarter model re-audited them against real logs
- **"No revenue is where the failure is"** — too early on purpose, betting that agent-to-agent commerce arrives the moment a competent robot lands on the phone
- **Trust takes years** — anti-persuasion checks, prompt-injection tests, a homegrown model router built before OpenRouter existed, and fallbacks for when the rate limits hit
- **Benchmarking his own router** — Venice, OpenAI, xAI, and Claude scored on price, latency, and intelligence, with and without the harness, fed back into model selection
